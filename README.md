# Sistema Unificado V5 — Frontend

Frontend React/Vite unificado, conservando la arquitectura del sistema actual y la experiencia funcional del V5.

## Funciones integradas
- Tienda pública, secciones y catálogo
- Carrito y checkout
- Login, registro, recuperación y cuenta
- Listas de precios
- Pedidos y presupuestos
- Panel administrativo
- Dashboard y estadísticas
- Productos, categorías, variantes e imágenes
- Clientes/usuarios y aprobación
- Cupones y promociones
- Pop-ups, páginas, badges y menú
- Métodos de pago
- Diseño, slider y configuración
- Redes sociales
- Envíos personalizados / Andreani
- Favoritos y carrito abandonado
- Importación y ajuste de precios
- Exportación CSV
- Modo prueba

## Configuración
Crear `.env` si hace falta:

`VITE_API_URL=https://TU-API` 

Luego:

```bash
npm install
npm run build
```
